Sync between iPhone and Mac

Uses your own free Firebase project (Firestore). Data lives in your account, not ours.
Enable cloud sync
Turns on real‑time sync across every device using this setup.
About "indefinite" rules: Firebase's default test‑mode rules expire after 30 days. The rules below never expire — but "anyone who has the config and Sync ID can read/write" is the trade‑off for that simplicity. Treat your Sync ID as a secret, and don't publish this page's config publicly. If you ever want it locked down further, add Firebase Authentication and I can tighten the rules to a single signed‑in user.
Paste this into Firebase Console → Firestore Database → Rules:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /ledgers/{syncId} {
      allow read, write: if true;
    }
  }
}
Data is saved to this device automatically. Add this page to your Home Screen on iPhone (Share → Add to Home Screen) for an app‑like feel.
